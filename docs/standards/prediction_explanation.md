# 예측 설명·확률 신뢰도·실패 사례 분석

## 목적과 범위

[Issue #36](https://github.com/Ahn-SooHyun/kbo-insight-ai/issues/36)의 실행 계약이다. 고정 최종 평가와 시즌 전망·보조 분석 검증 산출물을 읽기 전용으로 연결한다. 운영 예측기 6개, 학습·선정·보정 파라미터 및 시간 분할을 변경하지 않는다. Test는 설명과 진단에만 사용한다. 이 문서는 구현 계약이며 실행 성공이나 성능을 선확정하지 않는다.

## 실행과 고정 자료

Python 3.12 환경에서 저장소 루트 기준 `python -m src.explainability prepare`를 실행한다. 출력의 `plan`과 `sha256`을 보관한다. `python -m src.explainability run --plan <plan> --sha256 <sha256>`를 두 번 실행하고 각각의 `result`를 보관한다. `python -m src.explainability verify --plan <plan> --sha256 <sha256> --first <result1> --second <result2>`로 두 결과의 지문과 결정론적 핵심 산출물을 비교한다. 각 명령의 종료 코드 0과 완료 상태를 함께 확인한다. 전용 테스트와 전체 회귀도 별도로 실행한다.

최종 평가 실행 `7d125b8a685a4693a34aea70445ef294`와 시즌 검증 실행 `015a0df87fc7416da307ad0565c0774f`의 고정 명세 및 결과 SHA-256, 연결 파일의 지문, 운영 모델 내부 지문, 모델 DB 지문을 검사한다. 과거 실행의 소스 인벤토리와 현재 설명 실행 인벤토리를 구분한다. 설명 명세에는 현재 환경, 입력 지문, 설명 배경, 표본 선택 및 지표 정의를 기록한다. 각 실행은 새로운 결과 폴더에 저장한다. 실패 결과와 부분 산출물은 삭제하거나 덮어쓰지 않는다.

## 설명 방법과 척도

| 예측기  | 설명 및 기준                                                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M1      | 홈·원정 이력 기반 프로파일, Train 홈·원정 기준 PMF, 프로파일 PMF와 동점 가중 결합 분포. 기대득점 변화 및 승무패 확률을 검산한다.                            |
| M2      | 실제 인코딩의 Train 평균 기준 독립 개입 선형 SHAP(보정 전 로짓), 마스킹·사전 혼합·저장 온도 및 클래스 절편 보정.                                            |
| M4      | 저장 Train 평균과 표준편차에 따른 표준화 로짓 선형 SHAP, Sigmoid, RE 조건부 통계 및 종료 근거. 공식 종료로 확정한 값과 저장한 일반 추론값은 구분한다.       |
| M5      | 실제 활성 특징과 미출현 ID 후퇴를 반영한 Train 평균 기준 독립 개입 선형 SHAP(저장 온도 반영 공동 로짓), Softmax·사전 혼합, 공동 확률에서 두 주변 확률 합산. |
| M3 타자 | Train 일수당 사전 통계, 관측 시즌·최근 기록과 후퇴, 기간 환산 및 일관성 투영.                                                                               |
| M3 투수 | 이력 기준, 실제 공동 잔차 트리 분기·잎·지원, 축소와 척도 적용, 최종 일관성 투영.                                                                            |

선형 로짓에서 기준값은 `b + sum(w_j * mu_j)`, 기여는 `w_j * (x_j - mu_j)`이다. 희소 벡터는 활성 특징별 기여 및 비활성 특징 합계로 표현하고 배경 평균과 실제 저장 계수에서 각 비활성 특징 기여를 복원할 수 있다. 로짓 기여도는 최종 확률의 가산 분해가 아니며 상관관계 조건부 SHAP 또는 인과 효과가 아니다. M3의 투영·M1 분포 규칙은 SHAP으로 표시하지 않는다. 별도 SHAP 패키지를 추가하지 않는다.

## 표본 및 진단

Train 배경은 정답 접근 차단 연결에서 적격 학습 입력을 순차 읽어 계산한다. M4는 기존 Train 가중 평균을 재사용한다. 전체 설명은 각 모델의 고정 Test 표본에서 Seed 42와 표본 ID의 SHA-256 순서로 최대 2,000개를 선택한다. 개별 실패 사례는 사유별 오류 내림차순 및 ID 오름차순 최대 5개로 별도 선정한다. 실패 사례를 전체 중요도 표본에 추가하지 않는다. 전체 중요도는 선택된 표본의 평균 절대 기여 또는 모델별 계산 단계 변화·분기 사용률로 집계한다. 전체 신뢰도 및 실패 건수는 적격 Test 전량에서 계산한다.

M1 신뢰도 구간은 기존 비균등 경계(0, .01, .02, .05, .1, .2, .3, .4, .5, .6, .7, .8, .9, 1)를 유지한다. M2/M4/M5는 기존 10개 동일 폭 구간을 사용한다. 빈 구간과 관측률 0을 구분하고 1은 마지막 구간에 포함한다. ECE는 구간별 평균 예측과 관측 비율 차이의 절댓값을 해당 구간 분모로 가중한다. Macro Classwise ECE와 Top-label ECE를 혼용하지 않는다. M2의 신규 희소 분석 기준은 Train 1~29건, M5는 기존 1~49건이다. 0건은 미출현으로 구분한다. 구간 희소 표시는 1~29건이며 보정 판단의 합격 임계값이 아니다.

M3의 7일·28일·잔여 기간 정답 마스크, 구간 폭·포함률·공통 분모, 비율 분모 0 및 목표 포함률은 기존 최종 평가 계약을 따른다. 구간은 주변 기록별 구간으로 동시 포함을 보장하지 않는다. 실제 관측된 0을 미관측으로 치환하지 않는다.

## 시즌과 선발 해석

정규시즌 1위와 한국시리즈 우승은 별개 사건이다. 개별 팀의 유효 반복 조건부 확률, 모든 팀의 공동 확정 반복, 대진이 형성된 조건부 반복, 미결정 이유와 가능한 전체 반복 확률 범위를 구분한다. Seed·반복 수 변경에 따른 수치 변화는 계산 안정성 진단이지 실제 경기 불확실성의 신뢰구간이 아니다. 2025년 당시 일정 및 선수 정보의 공개 시각이 검증되지 않은 사후 개발·가정 시나리오이며 2026년 시즌 전망·보조 분석의 지원 제한을 유지한다. 2025년 한국시리즈 5차전 원천 홈·득점 표기 충돌로 종료 재생의 우승 분모가 0인 경우를 실제 경기 결과의 부재나 모델 오분류로 해석하지 않는다. 공식 사실 대조와 전체 원천 정확성 확인 범위는 선행 검증의 제한을 유지한다. 예상 선발 후보 순위는 확률이 아니며 후보 제공률, 실제 선발 식별률, Top-k와 공통 분모를 별도 제공한다.

## 결과와 검증

`results/prediction_explanation/<plan_id>/`의 설명 명세와 각 실행의 `result.json`을 시작점으로 사용한다. 모델별 설명 JSONL에는 고정 평가 표본 키·원래 예측·정답·설명·검산 기록을 남긴다. 모델별 JSON에는 전체 중요도·진단 지표·실패 사유와 표본 수를 남긴다. 시즌 JSON은 고정 결과의 요약·가정·검증 근거 및 보조 분석을 연결한다. 원천 대용량 예측·정답은 선행 실행 경로와 지문으로 참조하며 중복 복사하지 않는다. 검산 허용 오차는 수치 비교의 절대·상대 1e-9이며 정수·문자열·불리언·결측 및 키의 일치는 정확히 검사한다. 지표의 기존 분모와 정의를 유지한다. 실패·미지원 및 진단상의 악화는 성공 상태와 별도로 기록하며 성능 개선을 합격 조건으로 사용하지 않는다.
